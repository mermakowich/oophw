# Пояснительная записка

Калькулятор многочленов (вариант 11). Прохождение этапов из п.1 задания.

## 1. Пользовательские классы

| Класс | Назначение |
|-------|------------|
| `Polynomial` | Неизменяемый многочлен с вещественными коэффициентами; хранит массив `_coeffs`, где индекс = степень. Автоматически отбрасывает старшие нулевые коэффициенты. |
| `Calculator` | Калькулятор с накопителем `Current`. Выполняет операции над текущим многочленом и операндом, пишет каждое действие в `Logger`. |
| `Logger` | Журнал работы. Открывает/создаёт файл `calculator.log`, добавляет строки с меткой времени, умеет читать и очищать файл. |
| `MainForm` | Главная форма WinForms: ввод A и B, кнопки операций, поля результата и остатка. |
| `LogViewerForm` | Форма просмотра протокола. |

## 2. Алгоритмы и перегруженные операции

Перегружены: `+`, бинарный и унарный `−`, `*`, `/`, `%`, `==`, `!=`.

- **Сложение / вычитание** — поэлементно по массивам коэффициентов.
- **Умножение** — наивная свёртка O(m·n): `result[i+j] += a[i]·b[j]`.
- **Деление** — «уголком» (метод `DivMod`), возвращает частное и остаток через `out`-параметры. Делает копию массива остатка и последовательно вычитает делитель, умноженный на старший коэффициент.
- **Возведение в степень** — быстрое (binary exponentiation), O(log n) умножений.
- **Вычисление значения** — схема Горнера, O(n) умножений и сложений.
- **Разбор строки** — `Parse`: разделители — пробел, запятая, точка с запятой; запятая в числе допускается как десятичный разделитель.

## 3. Графический интерфейс

Главное окно (`MainForm`) состоит из четырёх блоков:

1. **Многочлен A** — пять полей `a0`…`a4`, кнопка «Загрузить A в результат».
2. **Многочлен B** — пять полей `b0`…`b4` (операнд).
3. **Операции** — кнопки `A+B`, `A−B`, `A×B`, `A/B (с остатком)`, `A^n`, «Вычислить A(x)», «Сброс результата».
4. **Результат** — поля «Результат» и «Остаток», подписанные многочлены в обычной записи + список коэффициентов.

Дополнительно: «Скопировать результат в A» (для цепочек вычислений), «Открыть протокол…», «Выход». Есть форма `LogViewerForm` со скроллом, кнопками «Обновить» и «Очистить».

## 4. Обработка исключительных ситуаций

Все обработчики кнопок обёрнуты в `SafeRun(Action)`, который ловит `Exception` и показывает `MessageBox` с текстом ошибки; одновременно ошибка пишется в протокол с пометкой `ОШИБКА:`.

Бросаемые/перехватываемые исключения:

| Ситуация | Исключение |
|----------|------------|
| Нечисловой коэффициент в поле | `FormatException` |
| Слишком много коэффициентов (> 5) | `FormatException` / `ArgumentException` |
| Нечисловое значение `x` или показателя `n` | `FormatException` |
| Отрицательный показатель степени | `FormatException` |
| Деление на нулевой многочлен | `DivideByZeroException` |
| `null`-аргументы в API классов | `ArgumentNullException` |

## 5. Отладка и тестирование

Основная логика покрыта 38 модульными тестами (запускались отдельно от GUI):
конструктор и нормализация, индексатор, операторы `+ − * / %`, унарный `−`,
`Power(0..4)`, `Evaluate` (Горнер), `DivMod` с нулевым и ненулевым остатком,
деление на ноль, `Parse` (три разделителя), отказ на «слишком много
коэффициентов» и нечисловой ввод, цепочка операций калькулятора и запись
в протокол. Все тесты прошли.

Ручная отладка интерфейса проводилась в Visual Studio: проверены типичные
сценарии (сложение, умножение многочленов 4-й степени → результат 8-й
степени; деление `x⁴−1` на `x−1`; возведение `(x+1)` в 4-ю степень
→ `x⁴+4x³+6x²+4x+1`; деление на 0; пустые поля).
