# Калькулятор многочленов (вариант 11)

Домашнее задание по дисциплине «Объектно-ориентированное программирование».

**Вариант 11** — Калькулятор многочленов (до 4-й степени, задаются коэффициентами).
Операции: сложение, вычитание, умножение, деление (с остатком), возведение в
целую неотрицательную степень, вычисление значения многочлена в точке, сброс
результата. Все действия записываются в файл протокола; протокол можно
просмотреть из самой программы.

Язык: **C#** (LangVersion 7.3), графический интерфейс: **Windows Forms,
.NET Framework 4.7.2** — предустановлен на любой Windows 10/11, дополнительные
runtime-ы ставить не нужно.

## 2. Запуск на любом компьютере с Windows

На Windows 10/11 .NET Framework 4.7.2 (и более поздние) уже установлен,
поэтому ничего ставить не нужно.

### Способ 1 — открыть в Visual Studio

1. Клонировать (или скачать ZIP-архивом и распаковать) репозиторий.
2. Двойной щелчок по `PolynomialCalculator.sln` — откроется в **Visual Studio
   2017 / 2019 / 2022**.
3. Нажать **F5** (или зелёную «стрелку» Start) — проект соберётся и запустится.

### Способ 2 — собрать из командной строки

Если установлен только **Build Tools for Visual Studio** или **MSBuild**:

```cmd
"C:\Program Files\Microsoft Visual Studio\2022\BuildTools\MSBuild\Current\Bin\MSBuild.exe" PolynomialCalculator.sln /p:Configuration=Release
```

Готовый `PolynomialCalculator.exe` появится в
`PolynomialCalculator\bin\Release\`. Запускается двойным щелчком.

### Способ 3 — просто запустить готовый .exe

После одной сборки `bin\Release\PolynomialCalculator.exe` можно
скопировать на любой другой Windows-компьютер и запустить — никакие
runtime'ы доустанавливать не требуется.

## 3. Как пользоваться программой

1. Введите коэффициенты многочлена **A** в верхней панели: `a0` — свободный
   член, `a1` — при x, …, `a4` — при x⁴.
2. Нажмите **«Загрузить A в результат»**, чтобы поместить многочлен в
   накопитель калькулятора (как кнопка «MS» на обычном калькуляторе).
3. Введите коэффициенты многочлена **B** в средней панели.
4. Нажмите нужную операцию:
   * **A + B**, **A − B**, **A × B** — соответствующие операции;
   * **A / B (с остатком)** — деление многочленов «уголком»; кроме частного
     выводится остаток;
   * **A ^ n** — возведение A в указанную целую неотрицательную степень;
   * **Вычислить A(x)** — значение текущего многочлена A в точке x;
   * **Сброс результата** — обнуление накопителя.
5. Кнопка **«Скопировать результат в A»** переносит полученный многочлен
   обратно в поля коэффициентов A — это удобно для последовательных
   вычислений (например, `((A+B) × C)^2`).
6. Кнопка **«Открыть протокол…»** показывает текстовый файл протокола
   `calculator.log` (создаётся рядом с исполняемым файлом). В окне просмотра
   можно обновить его или очистить.

### Десятичный разделитель

В полях коэффициентов допустимы и точка, и запятая: `1.5` ≡ `1,5`.

### Проверка корректности ввода

* Нечисловые символы → диалог с сообщением об ошибке.
* Показатель степени должен быть целым и неотрицательным.
* Деление на нулевой многочлен запрещено.
* Слишком много коэффициентов (более 5) → ошибка.
* Все ошибки также фиксируются в протоколе с пометкой `ОШИБКА:`.

## 4. Описание пользовательских классов

### `Polynomial` ([Polynomial.cs](PolynomialCalculator/Polynomial.cs))

Неизменяемый класс многочлена с вещественными коэффициентами.

* Поле `_coeffs` — массив коэффициентов; `_coeffs[i]` соответствует степени
  `x^i`. Старшие нулевые коэффициенты автоматически отбрасываются
  («нормализация»).
* Свойство `Degree`, индексатор `this[int power]`, метод `ToArray()`.
* Перегруженные операторы: `+`, бинарный и унарный `-`, `*`, `/`, `%`,
  `==`, `!=`.
* Статический метод `DivMod` — деление «уголком», возвращает частное и
  остаток через `out`-параметры.
* `Power(int n)` — быстрое возведение в степень (метод последовательных
  возведений в квадрат, схема «binary exponentiation»).
* `Evaluate(double x)` — вычисление значения по **схеме Горнера**.
* `Parse(string)` — разбор строки с коэффициентами (разделители: пробел,
  запятая, точка с запятой).
* `ToString()` — человекочитаемое представление вида `x^4 + 4*x^3 + 6*x^2 + 4*x + 1`.
* `ToCoefficientList()` — список коэффициентов в формате `[1, 4, 6, 4, 1]`.

### `Calculator` ([Calculator.cs](PolynomialCalculator/Calculator.cs))

Калькулятор с «накопителем» (свойство `Current` типа `Polynomial`).

* Методы: `Reset`, `SetCurrent`, `Add`, `Subtract`, `Multiply`, `Divide`,
  `Power`, `EvaluateAt`.
* После каждой операции `Current` обновляется и в `Logger` пишется строка
  протокола.

### `Logger` ([Logger.cs](PolynomialCalculator/Logger.cs))

Журнал работы калькулятора.

* Конструктор принимает путь к файлу.
* Методы: `Log`, `LogError`, `LogSession`, `ReadAll`, `Clear`.
* Все записи снабжаются меткой времени.

### Формы

* `MainForm` — главное окно: поля коэффициентов A и B, кнопки операций,
  поля результата и остатка, поля показателя степени и точки `x` для
  вычисления значения.
* `LogViewerForm` — окно просмотра протокола: загрузка содержимого файла,
  обновление, очистка.
